ШАХМАТЫ — ИГРА ВДВОЁМ НА ОДНОМ ПК И ПО LAN

ЗАПУСК
Откройте ChessLAN.exe. Установка Python не нужна.
Можно передать другу только ChessLAN.exe, остальные файлы не обязательны.
Сборка предназначена для Windows x64.

ИГРА ПО СЕТИ
1. Подключите оба ПК к одному роутеру (Wi-Fi или кабель).
2. Запустите ChessLAN.exe на обоих ПК.
3. На обоих ПК нажмите «Играть по сети LAN».
4. Если Windows запросит доступ к сети, разрешите его для частной сети.
5. Выберите друга в списке и нажмите «Пригласить выбранного игрока».
6. Друг получит приглашение и должен его принять.

Приглашающий играет белыми, принявший приглашение — чёрными.
Доска автоматически разворачивается своей стороной к игроку.
Можно ходить только своими фигурами и в свою очередь.
Новая партия, отмена хода и ничья согласуются со вторым игроком.
При обрыве связи партия останавливается. Чтобы начать снова,
нажмите «Выйти из LAN» и отправьте новое приглашение.
Приглашение действует 35 секунд; предложение во время игры — 60 секунд.

ЕСЛИ ДРУГ НЕ ПОЯВЛЯЕТСЯ
Откройте LAN на обоих ПК и разрешите ChessLAN.exe в брандмауэре
для частной сети. Поиск использует UDP 47853; партия — TCP-порт,
который показан в окне LAN. Не нужно открывать порты на роутере в интернет.
Вместо поиска можно нажать «Подключиться по IP и порту» и ввести
адрес из окна LAN друга, например 192.168.1.15:54321.
Гостевая Wi-Fi сеть или изоляция клиентов роутера может блокировать
связь между ПК: оба игрока должны находиться в сети без такой изоляции.
Прямое подключение также требует разрешения в брандмауэре.

УПРАВЛЕНИЕ
Перетаскивайте фигуры или нажмите сначала на фигуру, затем на клетку.
Подсвечиваются только разрешённые ходы. Поддерживаются рокировка,
взятие на проходе, выбор фигуры при превращении пешки, шах, мат и пат.
Ctrl+Z — отмена последнего хода (по LAN требует согласия друга).
Esc — снять выделение. «Перевернуть доску» меняет только ваш обзор.
История хранится до закрытия окна или начала новой партии.

ИСХОДНИК
chess.py — полный Python-скрипт, включая сетевой режим.
Для запуска исходника нужен Python 3 с Tkinter, без сторонних пакетов.
