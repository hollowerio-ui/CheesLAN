# CheesLAN
Шахматы для Windows с перетаскиванием фигур, игрой вдвоём на одном ПК и по LAN, автоматическим поиском игроков и приглашениями. EXE работает без установки Python.

♟️ Chess LAN
Шахматы для двух игроков с удобным графическим интерфейсом. Играйте на одном компьютере или по локальной сети — через Wi-Fi или кабель от одного роутера.
Возможности
- Перетаскивание фигур мышкой и подсветка допустимых ходов.
- Игра вдвоём на одном ПК.
- Игра по LAN с автоматическим поиском игроков.
- Приглашения в партию с подтверждением.
- Подключение по IP и порту, если автоматический поиск недоступен.
- Рокировка, взятие на проходе и выбор фигуры при превращении пешки.
- Определение шаха, мата, пата и основных ничейных позиций.
- История ходов, отмена хода и переворот доски.
- В сетевой игре отмена хода, новая партия и предложение ничьей согласуются со вторым игроком.
Запуск
Откройте ChessLAN.exe. Установка Python и дополнительных библиотек не требуется.

Готовая сборка предназначена для Windows x64.
Игра по локальной сети
1. Подключите оба компьютера к одному роутеру.
2. Запустите игру на каждом компьютере.
3. На обоих ПК нажмите «Играть по сети LAN».
4. Выберите друга в списке и отправьте приглашение.
5. После принятия приглашения начнётся партия.
Приглашающий играет белыми, второй игрок — чёрными. Доска автоматически разворачивается к каждому игроку его стороной.

Если Windows запросит разрешение на доступ к сети, разрешите его для частной сети.
Если игрок не появляется в списке
Используйте кнопку «Подключиться по IP и порту». Адрес отображается в окне LAN второго игрока.

Автоматический поиск использует UDP 47853, а партия — отдельный TCP-порт, указанный в окне LAN. Гостевая Wi-Fi сеть или изоляция клиентов на роутере может блокировать соединение между компьютерами.

При потере соединения партия останавливается. Для продолжения игры нужно начать новую сетевую партию.
Управление
Действие	Управление
Сделать ход	Перетащить фигуру или нажать на фигуру и целевую клетку
Отменить ход	Кнопка «Отменить ход» или Ctrl+Z
Снять выделение	Esc
Изменить обзор	Кнопка «Перевернуть доску»
Выполнить рокировку	Переместить короля на две клетки


Запуск из исходного кода
Нужен Python 3 с Tkinter. Сторонние Python-пакеты не требуются.
python chess.py

Python · Tkinter · TCP · UDP · PyInstaller
